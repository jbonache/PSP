    3. Gestió E/E de processos en Java

    Introducció

    Com ja hem vist en l'apartat inicial d'aquesta unitat, l'entrada i eixida dels processos pot utilitzar-se per a compartir informació entre ells.

    Hem de tenir en compte, que quan llancem un procés des dels nostres programes, aquests processos no tenen una terminal associada sobre la qual operar amb l'entrada i eixida.

    Per exemple, el següent codi, intenta llançar el ordre ps aux mitjançant la classe ProcessBuilder:

    ProcessBuilder pb = new ProcessBuilder("ps", "aux");
Process p = pb.start();

    Encara que compilaria i s'executaria sense problemes, no seria capaç de mostrar res per pantalla.

    En aquest apartat, veurem com podem accedir a aquesta informació proporcionada pels processos que llancem mitjançant l'ús de Streams d'entrada i eixida associada a aquests.

    Gestió de l'entrada i l'eixida de processos mitjançant Streams

    Com comentem, els processos creats bé amb ProcessBuilder o amb Runtime.exec no disposen d'una terminal (tty) associada, per la qual cosa no podem treballar directament amb les entrades i eixides estàndard del procés. Per a això, la classe Process ens ofereix Streams o fluxos de bytes associats l'entrada i eixida, i als quals podem accedir mitjançant els següents mètodes:

    • OutputStream getOutputStream(): Retorna el flux d'eixida connectat a l'entrada estándard del procés.
    • InputStream getInputStream(): Retorna el flux d'entrada connectat a l'eixida estàndard del procés.
    • InputStream getErrorStream(): Retorna el flux d'entrada connectat a l'eixida d'error del procés.

    Hem de tindre present que la classe Process representa un procés, però no és el procés en si. Amb l'ús d'aquests mètodes, podem proporcionar informació al procés a través del flux d'eixida que tenim connectada a ell, i obtindre informació del procés mitjançant els fluxos d'entrada.

    Exemple 1. Mostrant la informació per pantalla

    Veurem un exemple com treballar amb aquests Streams d'entrada i eixida dels processos en el següent programa EjemploStreams1.java. En ell veiem com podem obtindre l'eixida estàndard d'un procés llançat per nosaltres i bolcar-la en la nostra pròpia terminal:

    import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;

public class EjemploStreams1 {

    public static void main(String[] args) {

        System.out.println("------------- Calendario del año 2026 -----------------");
        try {

            // En primer lugar, creamos el objeto ProcessBuilder,
            // y lo inicializamos con la orden que vayamos a utilizar
            // (en nuestro caso, `cal 2026`)
            ProcessBuilder pb = new ProcessBuilder("cal", "2026");

            // Lanzamos el proceso con Start, que nos
            // devuelve un objeto de tipo Process.
            Process p = pb.start();

            // Obtenemos la salida del proceso con getInputStream,
            // Y la volcamos por pantalla, pasándola por un InputStreamReader
            BufferedReader br = new BufferedReader(
                    new InputStreamReader(
                            p.getInputStream()));
            String line;
            while ((line = br.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }

    }
}

    En primer lloc, creem la instància de ProcessBuilder amb el ordre i executem aquest mitjançant el mètode start, obtenint l'objecte Process corresponent:

    ProcessBuilder pb = new ProcessBuilder("cal", "2026");
Process p = pb.start();

    Una vegada hem llançat el procés, obtenim el flux d'entrada connectat a l'eixida estàndard del procés:

    InputStream is=p.getInputStream();

    Per a poder llegir còmodament d'aquest Stream, el paquet java.io ens ofereix els decoradors InputStreamReader i BufferedReader, de manera que InputStreamReader recobreix a InputStream, codificant els bytes en caràcters, i BufferedReader recobreix a InputStreamReader, oferint mètodes per a llegir línies directament:

    InputStreamReader isr=new InputStreamReader(is);
BufferedReader br=new BufferedReader(isr);

    Encara que podem definir directament la variable br sense la necessitat de definir variables intermèdies, de la següent manera:

    BufferedReader br = new BufferedReader(
new InputStreamReader(
       p.getInputStream()));

    Amb aquests decoradors, podrem llegir directament línies a partir de l'eixida estàndard del procés:

    String line;
while ((line = br.readLine()) != null) {
System.out.println(line);
}

    Sobre la codificació de caràcters

    Un aspecte a tindre en compte quan treballem amb streams és la codificació de la informació que s'intercanvia entre els processos, i que depén del sistema operatiu en què estiguem treballant. La majoria de sistemes (GNU/Linux, Mac US, Android, iOS..) utiizan la codificació UTF-8, basada en l'estàndard Unicode. Per contra, MS Windows utilitza els seus propis formats, incompatibles amb la resta, com Windows-1252. Així que per a tractar les dades correctament en Java quan fem ús de mecanismes de comunicació entre processos més avançats, caldrà tindre en compte el tipus de codificació que el propi sistema utilitza.

    Exemple 2. Redirecció a fitxers

    En el següent programa EjemploStreams2.java, tenim un exemple sobre com redirigir aquesta eixida cap a un fitxer, utilitzant per a això els decoradors FileWriter i BufferedWriter:

    import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.File;
import java.io.FileWriter;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;

public class EjemploStreams2 {

    public static void main(String[] args) {

        try {

            // En primer lugar, creamos el objeto ProcessBuilder,
            // y lo inicializamos con la orden que vayamos a utilizar
            // (en nuestro caso, `cal 2026`)
            ProcessBuilder pb = new ProcessBuilder("cal", "2026");

            // Lanzamos el proceso con Start, que nos
            // devuelve un objeto de tipo Process.
            Process p = pb.start();

            // Obtenemos la salida del proceso con getInputStream,
            // Y la volcamos por pantalla, pasándola por un InputStreamReader
            BufferedReader br = new BufferedReader(
                    new InputStreamReader(
                            p.getInputStream()));

            // Volcamos la salida a un fichero, utilizando el decodador
            // BufferedWriter, de forma similar al ejemplo anterior
            BufferedWriter bw = new BufferedWriter(
                    new FileWriter(new File("calendario2026.txt")));

            // Escribimos la cabecera
            bw.write("------------- Calendario del año 2026 -----------------");

            // Leemos del stream y escribimos en el fichero
            String line;
            while ((line = br.readLine()) != null) {
                bw.write(line + "\n");
            }
            bw.close();

        } catch (IOException e) {
            e.printStackTrace();
        }

    }
}

    Com veiem, una vegada tenim preparat el BufferedReader br per a la lectura del procés, en lloc de mostarlo per pantalla, ho bolquem al disc de la següent manera:

                    new FileWriter(

new File("calendario2026.txt")));
String line;
while ((line = br.readLine()) != null) {
    bw.write(line + "\n");
}
bw.close();

    Amb això generarem el fitxer calendario2026.txt , el contingut del qual serà l'eixida que abans mostràvem per pantalla.

    Redirecció amb ProcessBuilder

    La classe ProcessBuilder ens ofereix una forma més simple de redirigir l'entrada i eixida d'un procés, ja siga cap a l'eixida estàndard, cap a un fitxer o qualsevol altra font o destinació de dades, a través de mètodes com redirectOutput, redirectInput o redirectError. Mitjançant aquests mètodes, únicament haurem d'indicar cap a on redirigir l'eixida

    Per a indicar aquesta redirecció, podem utilitzar la classe ProcessBuilder.Redirect, que pot prendre alguns dels següents valors:

    • ProcessBuilder.Redirect.PIPE: Per a indicar que el subprocés de E/S es connectarà al procés Java actual a través d'una canonada. Aquest és el comportament per defecte.
    • ProcessBuilder.Redirect.INHERIT: Per a indicar que el subprocés de E/S tindrà els mateixos fluxos de E/S que el procés actual.
    • ProcessBuilder.Redirect.DISCARD: Descarta l'eixida del subprocés.
    • Una redirecció per a llegir d'un fitxer, obtinguda mitjançant Redirect.from(fichero)
    • Una redirecció per a escriure en un fitxer, obtinguda mediant Redirect.to(fichero)
    • Una redirecció per a escriure al final d'un fitxer, obtinguda mitjançant el mètode Redirect.appendTo(fichero)

    Vegem alguns exemples d'això

    Exemple amb ProcessBuilder.Redirect.Inherit

    En el següent exemple EjemploRedirect1.java es mostra l'eixida del procés per la mateixa eixida que el procés Java, això és, la pantalla:

    import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.File;
import java.io.FileWriter;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;

public class EjemploRedirect1 {

    public static void main(String[] args) {

        System.out.println("------------- Calendario del año 2026 -----------------");
        try {

            // En primer lugar, creamos el objeto ProcessBuilder,
            // y lo inicializamos con la orden que vayamos a utilizar
            // (en nuestro caso, `cal 2026`)
            ProcessBuilder pb = new ProcessBuilder("cal", "2026");
            pb.redirectOutput(ProcessBuilder.Redirect.INHERIT);

            // Lanzamos el proceso con Start, que nos
            // devuelve un objeto de tipo Process.
            pb.start();

        } catch (IOException e) {
            e.printStackTrace();
        }

    }
}

    Com veiem, el programa defineix el processBuilder, redirigeix l'eixida com INHERIT, i inicia el procés:

    ProcessBuilder pb = new ProcessBuilder("cal", "2026");
pb.redirectOutput(ProcessBuilder.Redirect.INHERIT);
pb.start();

    Exemple per a redirigir l'eixida a un fitxer

    El següent programa EjemploRedirect2.java mostra com redirigir l'eixida a un fitxer mitjançant ProcessBuilder.Redirect.to:

    import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.File;
import java.io.FileWriter;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;

public class EjemploRedirect2 {

    public static void main(String[] args) {

        try {

            // En primer lugar, creamos el objeto ProcessBuilder,
            // y lo inicializamos con la orden que vayamos a utilizar
            // (en nuestro caso, `cal 2026`)
            ProcessBuilder pb = new ProcessBuilder("cal", "2026");

            File calendario=new File("calendario2026.txt");
            BufferedWriter bw = new BufferedWriter(
                    new FileWriter(calendario));
            bw.write("------------- Calendario del año 2026 -----------------\n");
            bw.close();

            // Para sobreescribir el fichero
            pb.redirectOutput(ProcessBuilder.Redirect.to(calendario));
            // Para ampliar el fichero
            //pb.redirectOutput(ProcessBuilder.Redirect.appendTo(calendario));

            // Lanzamos el proceso con Start, que nos
            // devuelve un objeto de tipo Process.
            pb.start();

        } catch (IOException e) {
            e.printStackTrace();
        }

    }
}

    Tinguem en compte que amb Redirect.to, sobreescriurem el contingut del fitxer. Si el que desitgem és mantindre el contingut, utilitzarem el mètode Redirect.appendTo. Per exemple:

    ProcessBuilder pb = new ProcessBuilder("cal", "2026");
File calendario=new File("calendario2026.txt");
BufferedWriter bw = new BufferedWriter(new FileWriter(calendario));
bw.write("------------- Calendario del año 2026 -----------------\n");
bw.close();
pb.redirectOutput(ProcessBuilder.Redirect.appendTo(calendario));

    ProcessBuilder i canonades: StartPipeline

    Canonades de ProcessBuilder

    L'API de ProcessBuilder incorpora el mètode estàtic StartPipeline que permet crear una canonada de processos en els quals l'eixida d'un procés s'envia a l'entrada del següent.

    Aquest mètode es defineix de la següent manera:

    static List<Process> startPipeline(List<ProcessBuilder> builders)

    Com veiem, aquest mètode rep una llista d'objectes de tipus ProcessBuilder, instanciats ja amb les seues propietats corresponents (ordres, entorn...), i retorna una llista d'objectes de tipus Process, com a resultat de la posada en marxa de cada procés.

    Així doncs, si desitgem crear una canonada per exemple amb l'eixida de:

    ps aux | grep root

    Definiríem la llista de builders amb els dos ProcessBuilder:

    List builders = Arrays.asList(
    new ProcessBuilder("ps", "aux"),
    new ProcessBuilder("grep", "root"));

    I invocaríem a startPipeline de la següent manera:

    List<Process> listaProcesos = ProcessBuilder.startPipeline(builders);

    Atés que el que ens interessa és l'eixida únicament de l'últim procés executat, obtindrem aquest mitjançant:

    Process ultimo = listaProcesos.get(listaProcesos.size() - 1);

    Amb el que ja podrem utilitzar els mètodes getInputStream i getErrorStream per a obtindre l'eixida de tots ells.
