    1. Introducció a Node.js

    Introducció

    Nodejs és un runtime o entorn a execució construït sobre el motor Javascript V8 de Google Chrome, i que ens permet fer ús d'aquest llenguatge per a desenvolupar qualsevol tipus d'aplicació, constituyendose com un entorn fullstack (frontend i backend) complet. A més, en tractar-se d'un llenguatge lligat inicialment al món web, tenim la possibilitat de crear aplicacions d'escriptori o mòbils usant tecnologíes com HTML5 i CSS.

    Al lloc Octoverse (https://octoverse.github.com/) creat per Github, es mostra un informe anual de les tendències quant a desenvolupament de programari lliure, realitzat a través dels milions de projectes que s'allotgen en aquest portal. En aquest informe, podem veure com Javascript és des de lluny el llenguatge que més projectes de programari lliure utilitzen, seguit de Python en segon lloc i de Java en tercer.

    Documentació oficial

    Lloc web oficial amb la documentació de Node.js: https://Node.js.org/en/docs/

    Evolució de Javascript

    La primera versió de Javascript va ser dissenyada el 1995 per Netscape, amb la intenció de donar inicialment capacitat als navegadors per a la validació de formularis, sense necessitat d'enviar les dades al servidor per a ser validades en temps on la velocitat en les comunicacions era molt limitada. Aquesta primera versió, inicialment anomenada LiveScript, va passar a nomenar-se javaScript per pur màrqueting (java estava de moda en l'època).

    L'any 1997 s'estandaritza el llenguatge, donant lloc a la norma ECMA-262 ( European Computer Manufacturers Association), conegut com ECMAScript. L'ISO va adoptar l'ECMA-262 donant lloc a l'estàndard ISO/IEC-16262.

    Des de llavors, el llenguatge ha anat evolucionant i guanyant en capacitat, sent la versió ES6 (EcmaScript 2015) la que majors canvis va suposar, amb la introducció d'àmbits per a les variables, string templates, funciones fletxa, desestructuració, i sobredo, les classes i les promeses.

    Característiques principals de Nodejs

    Entre les característiques de Node.js, podríem destacar:

    • Ofereix un paradigma de programació basada en esdeveniments, a través d'una API asíncrona que no bloqueja el programa principal mentre espera una resposta, sinò que segueix l'execució principal fins que es rep la resposta.
    • L'execució de codi és molt ràpida,
    • Es basa en un model monohilo molt escalable: Únicament hi ha un fil d'execució atenent peticions, però que gràcies a l'API asíncrona i dirigida per esdeveniments, es poden atendre múltiples peticions per aquest fil, arribant a consumir molts menys recursos que un sistema multifil.
    • Com que l'execució no es realitza dins del navegador, s'elimina la necessitat de desenvolupar codi compatible amb cada navegador.

    On podem trobar Node.js?

    Nodejs es troba segurament en més llocs dels que podem imaginar. Veiem una llista d'aplicacions on s'utilitza Node.js, tant des del costat de servidor com d'aplicacions d'escriptori i mòbils. Vegem alguns exemples:

    • Entorns de servidor (backend): Netflix, Paypal, LinkedIn, Ebay, NASA, Mozilla, Uber, Yahoo, Groupon (https://www.hackaboss.com/blog/5-mejores-ejemplos-de-aplicaciones-node-js-para-empresas),
    • Aplicacions d'escriptori:
      • Aplicacions d'escriptori basades en Electron (https://electronjs.org/apps): Skype, Whatsapp, Slack, Atom, Visual Studio Code, Github Desktop
      • Aplicacions basades en nwjs (https://github.com/nwjs/nw.js/wiki/list-of-apps-and-companies-using-nw.js): Haroopad, Reditr, TweetDeck, Kindle Cloud Reader.
    • Aplicacions mòbils amb Ionic/Capacitor: MarketWatch, Sanvello, Calla (https://mdevelopers.com/blog/14-best-ionic-apps-of-2022)

    Primers passos amb Node.js

    Instal·lació

    No hem de pressuposar que Ubuntu inclou una versió concreta de Node.js ni que aquesta siga adequada per al curs. En agost de 2026, Node.js 24 és la versió LTS més recent i Node.js 22 continua en manteniment LTS; Node.js 20 i versions anteriors ja han arribat al final de vida. Per als exercicis i per a producció utilitzarem una versió LTS compatible, preferentment Node.js 24.

    La pàgina oficial de descàrrega de Node.js mostra els mètodes d'instal·lació disponibles. Un gestor de versions permet instal·lar diverses versions sense modificar manualment els fitxers del sistema. Per exemple, amb nvm (eina comunitària) podem fer:

    $ nvm install --lts
$ nvm use --lts

    En un projecte compartit convé declarar també la versió mínima en package.json, per exemple amb "engines": { "node": ">=24" }, i conservar package-lock.json perquè les instal·lacions siguen reproduïbles.

    El que ens ofereix aquest paquet, tant el que tenim preinstal·lat al sistema com si l'instal·lem de nou és el propi node (o el seu àlies Node.js) i el gestor de paquets de Node.js, denominat npm (Node Package Manager).

    Hola Node

    Node.js pot llançar-se des de la pròpia terminal, amb l'ordre node o la seua àlias Node.js

    Per a comprovar la versió de node que tenim, farem ús de node -v o node --version:

    $ node -v
v24.18.0
    Node.js admet dues formes de treball: mitjançant la consola interactiva i l'execució directa de scripts.

    La consola interactiva

    Nodejs disposa d'una consola interactiva, a la qual podem accedir simplement amb node i llançar directament ordres:

    $ node
> console.log("Hola Node");
Hola Node
undefined

    Com podem veure, quan llancem node, el prompt del sistema canvia al símbol >, indicant que estem dins de la consola de Node. Si alguna vegada hem treballat amb la consola web del navegador, el funcionament és exactament el mateix.

    Si ens fixem, hem escrit només una instrucció console.log, que seria ho equivalen a Java a System.out.println. Podem veure, com no ens ha fet falta definir cap classe principal ni cap mètode main. Javascript, a pesar que suporta la programació orientada a objectes, no obliga al fet que tot, inclòs el programa principal estiga dins d'una classe. D'aquesta manera, podem tindre codi tan senzill com una simple instrucció.

    Veiem també que al final ens torna un valor undefined. Això es deu al fet que la funció console.log no retorna cap valor (és de tipus void), i per tant, ens indica que el resultat que retorna la funció no està definit.

    Per a eixir de la manera interactiva farem ús de la combinació de tecles Ctrl+D

    2.4. Execució de scripts

    La manera habitual en què funcionarem amb Node.js serà llançant l'ordre node sobre un script. Vegem-ho amb un senzill exemple. Tenim el script següent, denominat hola.js

    if (process.argv.length==3)
 console.log("Hola "+process.argv[2])
else
 console.log("Hola Nodejs");

    Per a executar-ho, utilitzarem node juntament amb el nom del fitxer:

    $ node hola.js Jose
Hola Jose
$ node hola.js 
Hola Nodejs
    Com veiem, es tracta d'un Hola Món personalitzat, on segons els paràmetres que li proporcionem, escriurà l'una o l'altra cosa. També podem observar, com s'ha comentat abans, que no ha fet falta incloure el codi en cap classe ni funció especial. A més, veiem que podem accedir als paràmetes que passem per la línia d'ordres a través de l'objecte (vector) process.argv, que la propietat process.argv.length ens dóna la longitud d'aquest, i que la segona posició d'aquest (process.argv[2]) fa referència al primer paràmetre que li hem passat.
