    2. El llenguatge JavaScript

    Introducció

    Com hem comentat, nodeJS es basa en el motor de Javascript V8 de Google Chrome, pel qual començarem amb una introducció a aquest llenguatge per a començar amb nodeJS.

    Veiem algunes generalitats del llenguatge:

    • Un programa o script en Javascript està compost de sentències, que poden o no acabar en ;. A pesar que no és obligatori, és recomanable el seu ús.
    • Els espais en blanc sobrants i les noves línies, no es tenen en compte, per la qual cosa admet qualsevol tipus de tabulació.
    • Els bloc de codi es defineixen seguint l'estil de llenguatges com a C o Java, amb claus {...}.
    • Es tracta d'un llenguatge case sensisive, per la qual cosa distingeix majúscules i minúscules.
    • Els comentaris també segueixen una sintaxi similar a C o Java:
    • // Dues barres per als comentaris d'una línia
    • /* Barra i asterisc per a comentaris de més d'una línia */
    • Paraules reservades: Aquelles que s'utilitzen per a construir sentències, i que no es poden utilitzar lliurement. Alguens d'aquestes són: break, caso, catch, class, continúo, default, delete, do, else, finally, for, function, if, in, instanceof, new, return, switch, this, throw, try, typeof, var, void, while, with.
    • A pesar que Javascript suporta programació orientada a objectes, no estem obligats a utilitzar-los. Per tant, no és necessari definir un mètode Main dins d'una classe, sinò que directament l'execució comença amb la primera línia de codi executable

    Elements del llenguatge

    Variables

    No és necessari declarar variables en Javascript, a pesar que és altament recomanable. Per a declarar una variable fem:

    let variable=valor;

    També es pot utilitzar var en lloc de let, però des de la versió ES2015, la recomanació és utilitzar let

    La manera strict

    Javascript ens permet treballar en manera strict, que ens obliga a declarar les variables abans d'utilitzar-les.

    Per exemple, el següent script (saluda.js):

    nombre="Jose";
console.log("Hola "+nombre);

    Funcionaria correctament:

    $ nodo saluda.js
Hola Jose

    Però si habilitem la manera estricta:

    'uso strict';

nombre="Jose";
console.log("Hola "+nombre);

    Ens mostraria el següent error:

    /tmp/prova1.js:3
nombre="Jose"

    Com veiem, el treballar amb la manera strict, ens obliga a definir variables, de manera que detectem fàcilment quan cometem algun error escrivint el nom d'aquestes.

    El nom de les variables

    • El nom de les variables pot contindre qualsevol caràcter alfanumèric, més el símbol $ i _.
    • Poden començar per qualsevol caràcter, més el $ i el _,però no per un número.
    • El nom de les variables sol indicar-se amb format CamelCase (la primera lletra de cada paraula en majúscules i la resta en minúscules).

    Tipus de variables i assignació dinàmica

    Una variable també pot ser inicialitzada en la declaració, i pot ser qualsevol valor, o el resultat d'una expressió.

    let variable=[ valor | expresión ];

    Una variable en javascript emmagatzema dades d'un tipus concret en un moment donat. Mitjançant la assignació dinàmica de tipus, el tipus de dada que emmagatzema aquesta variable pot canviar en temps d'execució. És a dir, el tipus d'una variable es defineix de manera dinàmica en el moment de la seua assignació, no de la declaració.

    Les variables poden ser:

    • Variables de tipus numèriques (number): Emmagatzema valors sencers o decimals (amb el caràcter . per a separar la part sencera de decimal).
    • Tipus text (string): Emmagatzema una llista de caracters, entre cometes, bé amb cometes simples o dobles. En cas que el text continga cometes, cal anar amb compte amb la construcció, no podent utilitzar internament les cometes que hem utilitzat per a definir la cadena de text o bé escapant aquestes:
    var texto="Esta frase utiliza 'comillas simples'"
var texto="Esta frase utiliza \"comillas dobles escapadas\""
    • Dins de les cadenes de text, també podem incloure:
    • Salts de línia: \n
    • Tabuladors: \t
    • Barra inclinada: \\
    • Cometes escapades: \" o \'

    Conversió de tipus

    La conversió de tipus es realitza de manera automàtica. En cas d'ambiguedad, utilitza prioritats:

    Exemple: '10'+3 : Suma un string i un number. En aquest cas, té prioritat la cadena de caràcters, per la qual cosa el number 3 es converteix al string '3'. En canvi, quan es tracta del + unari, només s'aplica als number, per la qual cosa +'20', representaria el número 20

    Vegem alguns exemples més:

    13 + 7 => 20
"13" + "7" => "137"
"13" + 7 => "137"
+"13" + 7 => 20

    Tipus lògic: Poden contindre els valores true i false

    let itemSelected=false;
let display=true;
    • Valors null i undefined: Quan una variable no s'ha definit, el tipus d'aquesta és undefined. En canvi, quan volem fer referència al valor nul, fem ús de null, sense cometes. Com veurem, el valor null serà un tipus especial d'objecte.

    Typeof

    Per a saber el tipus de dada que conté una variable en un moment donat, podem utilizarl operador typeof:

    > typeof(10)
'number'
> typeof("hola")
'string'
> typeof(true)
'boolean'
> typeof(a)
'undefined'
> typeof(null)
'object'
> typeof({"nombre":"jose"})
'object'

    Vectors i JSON

    Els vectors són col·leccions de valors/elements, bé del mateix tipus o de tipus diferent (a diferència altres llenguatges, que els tipus han de ser homogenis)

    Per a definir el vector utilitzem els caracters [ i ] al principi i al final, i utilitzem les comes (,) per a separar elements

    let nombre_vector = [valor1, valor2, ..., valorN];

    Exemples:

    let días_semana=["lunes", "martes", "miércoles", "jueves", "viernes", "sábado", "domingo"];
let ex_vector=["cadena1", num1, "cadena2", ["cadena1_vector1"]];
    Per a accedir als elements, indiquem la posició en el vector (la posició inicial és la 0):

    • Consulta: var hoy=día[1];
    • Assignació: ex_vector[1]="cadena3";
    • Un vector buit, es pot definir inicialitzant-lo a buit, o creant un nou objecte de la classe Array:
    ex_vector2=[];
ex_vector3=new Array();

    Per part seua, els elements JSON (Javascript Object Notation) són una forma més compacta d'emmagatzemar i transmetre informació que el format XML, a través de parells clau-valor

    Els els tipus de dades que podem representar en un JSON són:

    • Números, tant sencers com decimals,
    • Cadenes, expressades entre cometes i amb la possibilitat d'incloure seqüències de fuita,
    • Booleans, per a representar els valors true i false,
    • Null, per a representar el valor nul,
    • Array, per a representar llistes de zero o més valors, de qualsevol tipus, entre corxets i separats per comes,
    • Objectes, com a col·leccions de parells <clave>:<valor>, separats per comes i entre claus, i de qualsevol mena de valor

    Recordem un xicotet exemple d'aquesta notació:

    {
 "curso": [
 {
 "nombre": "Acceso a Datos",
 "horas": 6,
 "qualificacio": 8.45
 },
 {
 "nombre": "Programació de servicios y procesos",
 "horas": 3,
 "qualificacio": 9.0
 }
 ]
}

    Javacript suporta la manipulació d'elements JSON de manera nativa, de manera que no necessitem cap llibreria per a poder utilitzar aquest format.

    Declaració de constants

    Quan no desitgem que canvie el valor d'una variable o si volem definir un valor global immutable, es recomana utilitzar la paraula reservada const en lloc de let. Per a les constants globals es recomama usar majúscules.

    const PI=3.1416;

    Operadors

    Les variables es combinen entre elles, formant expressions mitjançant els operadors. Aquestes expressions, podran avaluar-se, donant lloc a un nou valor, que pot utilitzar-se per a prendre decisions en un script, o bé per a assignar-ho a noves variables.

    Els operadors poden ser d'assignació, aritmètics, lògics o relacionals.

    Operador d'assignació (=)

    S'utilitza per a assignar a una variable un valor o expressió.

    let variable1 = Expresión;

    Operadors aritmètics

    Els operadors artimètics són aquells que treballen amb valors de tipus numèrics per a obtindre altres valors de tipus també numèric. A més dels habituals de suma(+), resta (-), multiplicació (), divisió (/), i resta de la divisió (%), tenim els següents operadors:

    • Operadors d'increment (++) i decrement (--): per a incrementar o decrementar el valor d'una variable, i no té el mateix significat posar-lo davant que darrere de la variable.
    let a=2
let b=2
let c=++a + b;
>> c = 5
>> a = 3

    No és el mateix que:

    a2=2
b2=2
c2=a2++ + b2
>> c2 = 4
>> a2 = 3
    • Suma/resta Combinada (+= i -=): Igual que en C i Java, podem utilitzar expressions tipus a+=3 per a simplificar l'expressió a=a+3

    Operadors lògics

    Són aquells que s'apliquen sobre valors lògics i retornen un valor també lògic

    • Negació: !
    > let a=true;
> !a;
false

    Quan s'aplica sobre valors no lògics el significat és el següent: El valor numèric de 0 i la cadena de text buida es converteixen al valor lògic false, mentre qu eun número diferent a 0 i una cadena no buida es consideren true.

    • Operador and (&&): El resultat és cert si els dos operands ho són. Operador or (||): El resultat és cert si un dels dos operands ho és.

    Operadors relacionals

    Són aquells que operen amb qualsevol mena de dada, comparant-los i ens proporcionen un valor de tipus lògic.

    Operador Semàntica
    > Major que
    < Menor que
    >= Major o igual
    <= Menor o igual
    == (Compte amb =) Igual que
    5=="5" ==> true
    === Igual que, en valor i tipus.
    5==="5" ==> false
    != Diferent de
    !== Diferent, o de tipus diferent

    Quan treballem amb cadenes, els operadors relacionals el que fan és comparar lletra a lletra, els caràcters ASCII de dues cadenes, d'esquerra a dreta

    Altres operadors

    A més dels operadors tradicionals, javascript aporta alguns operadors més:

    • Operador condicional ternari: L'operador condicional ternari, permet assignar un valor a una variable, basant-se en certa condició: el 
      variablename = (condition) ? value1:value2

    Per exemple:

    let mayor_edad = (edad < 18) ? "Menor de edad":"Mayor de edad";
    • Operador Typeof: Com ja hem comentat abans, aquest operador obté el tipus de valor d'una variable

    Funcions

    La delcaración d'una funció en Javascript es declara amb la paraula reservada function. A diferència de Java, les funcions poden declarar-se fora d'un objecte.

    function nombre_funcion(lista_argumentos) {
 // Cuerpo de la función
 }

    El nom de la funció s'utilitza per a fer referència a ella des de qualsevol part del codi. Si volem que la funció ens retorne algun valor, i assignar est a una variable, farem ús de la paraula reservada return. L'ordre dels arguments és important (pas de paràmetres posicional). A més, el número de les variables utilitzades quan s'invoca la funció no té per què coincidir amb el número que li donem als arguments en la declaració.

    Exemple:

    function suma(numero1, numero2) {
 resultado = numero1 + numero2;
 return resultado;
}

s=suma(a, b);

    Exemple:

    function calculaPrecio(precio) {
    precio_iva=(precio*1.21).toFixed(2); // Redondeamos a dos decimales
    precio_iva_reduicido=(precio*1.1).toFixed(2);

    Àmbit de les variables (scope)

    L'àmbit d'una variable és la part del programa on aquesta està definida, i on presa sentit. L'àmbit pot ser:

    • global, visible des de tot el script, o * local, visible solo en la funció on es troba declarada (amb var o let)

    Per a entendre bé l'àmbit de les variables, cal tindre en compte alguns aspectes:

    • Javascript és un llenguatge amb àmbit global com a àmbit predeterminat, i on tot es passa també de manera predeterminada per referència: quan declarem una variable fora d'una funció, aquesta és global, i es passa per referència als àmbits descendents o heretats (per tant, qualsevol modificació que fem a la variable en qualsevol àmbit tindrà efecte sobre ella).
    • Quan declarem una variable amb var dins d'una funció, es crea un variable local, amb visibilitat restringida a aqueixa funció.
    • Quan definim una variable amb let o una constant amb const, el seu àmbit es redueix als blocs on està definida.

    Programació estructurada en Javascript

    Estructures condicionals

    if

    Es tracta de la condició més senzilla:

    if (condición) {
 // bloque de código a ejecutar si la condición se evalúa a cierto
}

    Exemple 1 

    if (hora < 12) {
 saludo = "Buenos días";
}

    if / else

    if (condición) {
 // bloque de código a ejecutar si la condición se evalúa a cierto
} else {
 // bloque de código a ejecutar si la condición se evalúa a falso
}

    Exemple

    if (hora < 12) {
    saludo = "Buenos días";
} else {
    saludo = "Buenas tardes";
}

    else if

    Quan poden donar-se diverses condicions alternatives, podem utilitzar l'estructura else/if

    if (condición1) {
    // bloque de código a ejecutar si la condición 1 se evalúa a cierto
} else if (condición2) {
    // bloque de código a ejecutar si la condición 2 se evalúa a cierto
} else {
 // bloque de código a ejecutar si ninguno de las dos condiciones se avalúa a cierto.
}

    Exemple

    if (hora < 12) {
 saludo = "Buenos días";
} else if (hora < 21) {
 saludo = "Buenas tardes";
} else {
 saludo = "Buenas noches";
}

    Switch

    S'utilitza quan volem realitzar diferents accions en funció de múltiples condicions sobre una expressió. Segons aquesta s'avalue, s'executarà un (o més, cuidat amb el break!) d'entre diversos blocs.

    switch(expresión) {
 case n1:
    // Bloque de código a ejecutar si expresión se evalúa a n1
 break;
 case n2:
    // Bloque de código a ejecutar si expresión se evalúa a n2
 break;
 default:
    // Bloque de código a ejecutar si la expresión se evalúa
    // a un valor no contemplado
}

    Exemple: Usant la funció Date().getDay() que retorna el dia de la setmana:

    switch (new Date().getDay()) {
    case 0:
        dia = "Diumenge";
        break;
    case 1:
        dia = "Dilluns";
        break;
    case 2:
        dia = "Dimarts";
        break;
    case 3:
        dia = "Dimecres";
        break;
    case 4:
        dia = "Dijous";
        break;
    case 5:
        dia = "Divendres";
        break;
    case 6:
        dia = "Dissabte";
        break;
    default:
       console.log("dia erroni");    }

    El break s'utilitza per a indicar que ja no cal continuar buscant més coincidències. Estalviem així comparacions innecessàries i errors. Cal tindre en compte que també es poden agrupar diversos cas (sense el break pel mitjà), quan hi ha codi comú.

    Exemple:

    switch (new Date().getDay()) {
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        dia = "dia laboral";
        break;
    case 0: // Diumenge
    case 6: // Dissabte
        dia = "cap de setmana";
        break;
    default:
       console.log("dia erroni");
}

    Estructures repetitives

    Bucle for

    S'usa generalment quan sabem per endavant quantes repeticions necessitem:

    for (inicialización; condición_de_repetición ; incremento ) {
    // Código a ejecutar
}

    Exemple:

    for (i = 0; i < 10; i++) {
    console.log("Indice: " + i); // Fixeu-vos que "sumamos" un string y un entero!
}

    Sintàcticament la inicialització, condició de repetició i l'increment no són necessàries, i el bucle anterior podria expressar-se com:

    var i=0;
for(;;){
 console.log(i++);
 if (i>10) break; // El break rompe el flujo del bucle
}
    D'altra banda, també podem inicialitzar diversos valors:

    *Exemple*: Per a mostrar els elements d'un vector:

    vector=["pera", "manzana", "plátano"];
for (i = 0, len = vector.length, texto = ""; i < len; i++) {
    console.log(vector[i]);
}

    Bucle for/in - for/of

    S'utilitza per a recórrer els elements d'un objecte:

    for(item in object){
    ...
}

    Exemple:

    let peli={title:"Han Solo: Una historia de Star Wars", director: "Ron Howard"};

for (index in peli) {
    console.log(index+":"+peli[index]);
}

    Així també podem indexar els elements d'un vector:

     v=[1,2,3,76,4,2,5]
 ...
> for (i in v) {
... console.log(v[i]);}

    Caution

    Un error habitual (per influència altres llenguatges de script) és confondre l'índex amb el valor de l'element:

    for (e in v) {
console.log(e);
} // Cuando el que queremos es acceder al contenido!

    Per a accedir directament als elements, el que ens ofereix Javascript és l'operador of. L'únic requeriment és que l'objecte sobre el qual l'apliquem siga iterable

    Per exemple, el següent codi que imprimeix els elements del vector mitjançant for..in:

    > for (i in v) {console.log(v[i])};

    Pot expressar-se més senzillament mitjançant for..of amb:

    > for (i of v) {console.log(i)};

   console.log(i);

    Programació Orientada a Objectes en JS

    En el paradigma d'orientació a objectes, el programari es dissenya a través d'objectes que cooperen, intercanviant-se missatges i responent a events, a diferència del punt de vista tradicional on es considera com un conjunt de funcions.

    Vegem alguns conceptes:

    • Classe: Defineix les característiques de l'objecte.
    • Objecte: Una instància de la classe.
    • Propietat/Atribut: Una característica (variable) de l'objecte.
    • Mètode: Una capacitat (funció) de l'objecte.
    • Constructor: Mètode que s'invoca en crear l'objecte.
    • Herència: Capacitat d'una classe d'heretar característiques d'una altra classe.
    • Encapsulamiento: Les propietats i els mètodes dels objectes es troben organitzats de manera estructurada, evitant l'accés des de qualsevol forma diferent a les especificades.
    • Polimorfisme: Mecanisme pel qual diferents classes poden implementar de manera diferent un mateix mètode.

    Orientació a Objectes basada en prototips

    Es tracta d'un estil de programació orientada a objectes on aquests no es creen a través de la instanciació de classes, sinó mitjançant la clonació altres objectes que fan de prototips. També es coneix com a programació sense classes, orientada a prototip o basada en exemples.

    Espais de noms

    En aplicacions grans, solem utilitzar els espais de noms per a evitar conflictes de noms amb entre els diferents scripts i llibreries que les componen. Aquests actuen com a contenidors que permeten associar la funcionalitat i les propietats d'un objecte amb un nom únic i aïllat de la resta. (Podria equiparar-se als packages de Java).

    En javascript no existeix una sintaxi nativa per a aqueixa funcionalitat, sinò que s'utilitza un objecte per a aquesta finalitat. Per exemple:

    var app={}
app.variable1 = 'variable1'
app.variable2='variable2'
app.funcion = function () { .... }

    La definició d'un objecte prototip en javascript no és més que una funció, que fa al mateix temps de constructor:

    function Objeto() { 
    // Constructor e inicialización de valores
    }

    I per a crear un nou objecte basat en aquest prototip, fem ús de new:

    var obj=new Objeto();

    Quan es defineix així un objecte, aquest té accés a una propietat especial, denominada prototip (prototype), que permet accedir a la classe en si

    Per a accedir a propietats dins d'una classe s'utilitza la paraula reservada this. Caldrà anar amb compte amb aquesta, ja que quan tenim objectes o propietats anidades, this sempre farà referència a l'objecte del nivell on es troba.

    Per a accedir des de fora de la classe a un atribut o mètode fem ús de la notació punt (.): Objeto.propiedad / Objeto.método

    Per exemple, per a definir la propietat nomene d'una classe persona, podem fer-ho en la creació de la instància:

    function Persona(nombre) {
    this.nombre = nombre;
}

    I per a instanciar dues noves persones:

    let persona1 = new Persona("Paco");
let persona2 = new Persona("Pepe");

console.log ('persona1 es ' + persona1.nombre); // muestra "persona1 se Paco"
console.log ('persona2 es ' + persona2.nombre); // muestra "persona2 se Pepe"

    Per a incloure mètodes, el que fem és definir funcions endins la classe:

    function Persona(nombre) {
 this.nombre = nombre;
 this.saluda=function(){
        alert('Hola, me llamo '+this.nombre);
    }
}

var persona1=new Persona('Paco');
persona1.saluda();

    Com veiem, els mètodes no són més que funcions que s'associen com una propietat a l'objecte, de manera que poden invocar-se fora del seu context

    Exemple

    Vegem un exemple complet per a la definició de classes, i que ens servirà per a veure altres conceptes com el de l'herència:

    /* Exemple de definició de classes */

function punt(x, y){
    /* 
         Funció constructor de la classe punt
       Rep dos paràmetres amb els que inicialitza 
       els atributs x i y
     */

    this.x=x;  // Definim atributs amb la paraula 
    this.y=y;  // reservada "this"

    this.get=function(){
        // Els mètodes no són més que funcions
        // Associades a la classe, i que definim
        // amb this, igual que un atribut.
        return "("+this.x+","+this.y+")";
    }
}

function figura(color, position){
    /*
        Classe figura, té com atributs un color
        i una posició (objecte de tipus punt)
    */

    this.color=color;     // Inicialitzem el color
    this.position=position; // Inicialitzem la posició

    this.draw=function(){
        /*
              Mètode que mostra un misstge donant 
          informació de la figura
        */
        console.log("Dibuixant figura en posició "+this.position.get()+
                      " i color "+this.color);
    }
}

function rectangle(color, posicio, costat1, costat2){

    /*
    Classe rectangle, que és una especialització de 
        la classe figura. De figura hereta:
        - l'atribut posició 
        - l'attribut color
    A més:
        - Inclou dos nous atributs: costat1 i costat2
        - Redefineix el mètode draw
        - Defineix un nou mètode area
    */

    this.costat1=costat1;
    this.costat2=costat2;
    /*
    Per heretar propietats de figura, 
    fem ús de "call", passant this com a 
    primer paràmetre, i els valors amb què
    volem invocar al constructor de la
    superclasse
    */

    figura.call(this, color, posicio);

    this.draw=function(){
        console.log("Dibuixant Rectangle de "+
                 this.costat1+"x"+this.costat2+
                 " en posició "+this.position.get()+
                 " i color "+this.color);       
        };

    this.area=function(){
        return this.costat1*this.costat2;
        }
    }


function cercle(color,posicio, radi){
    /*
    Classe cercle, hereta de figura: posició i color
    Afig l'atribut radi
    I redefineix el mètode draw i defineix area
    */

    this.radi=radi;
    // Apply és pot utilitzar també per heretar de la superclasse
    // La diferència és que requereix el pas de paràmetres a través
    // d'un vector:
    figura.apply(this, [color, posicio]);

    this.draw=function(){
        console.log("Dibuixant Cercle de radi "+this.radi+
                       " en posició "+this.position.get()+
                       " i color "+this.color);
        };

    this.area=function(){
        return 2*this.radi*Math.PI;
        }
    }

p1=new punt(10,20);
p2=new punt(10,30);
p3=new punt(30,20);

f1=new figura("roig", p1);
f2=new rectangle("verd", p2, 40, 20);
f3=new cercle("blau", p3, 50)
f1.draw();
f2.draw();
f3.draw();

    Orientació a Objectes a partir d'ES6

    A partir de la versió EcmaScript 6, Javascript suporta una sintaxi per a l'orientació a objectes més pròxima a la de la resta dels llenguatges. Cal remarcar que no es tracta d'una reformulació del model d'objectes, sinò que simplement es dedica a proveir de definicions més clares i simples per al treball amb objectes.

    Declaració de classes

    Com en altres llenguatges, es pot declarar utilitzant la paraula class:

    class Clase{

}

let objeto = new Clase;

    Cal tindre en compte alguns detalls:

    • La classe no necessita d'arguments per a la seua definició, per la qual cosa pot no s'acompanya dels parèntesis(new Clase en lloc de new Clase()).
    • Atés que s'ha definit com a classe, el sistema no permetrà que s'execute com a funció (a diferència dels prototips), sinò que es reservarà com un constructor.
    • El contingut de la classe s'executa en manera "strict" de manera automàtica.
    • Les declaracions de classe no segueixen les regles del *hoisting* (la declaració pot ser posterior a l'ús). Això significa que les classes només existeixen després de ser declarades.
    • Una classe es comporta implícitament com una constant, per la qual cosa no es pot redeclarar més endavant en un mateix àmbit

    Vegem la declaració de classe de forma més ampliada:

    class  Classe{
    constructor (arguments){
        // super (arguments); 
        // Declaració d'atributs amb this
    }

    get getAtribut(){
        // getter; compte que el nom no siga el
        // mateix que l'atribut

        return (this.atribut);
    }
    set setAtribut(valor){
        // setter; compte que el nom no siga el
        // mateix que l'atribut
        this.atribut=valor;
    }

    static staticMethod(){
        // Aquest és un mètode estàtic,
        // S'exectarà des de la classe, 
        // no des de les instàncies d'aquesta.
    }

    Metode(){
        // Mètode públic
        // No existeixen per tant els privats o protegits
    }
}

    Veiem un altre exemple més complet:

    class Classe{
constructor(valor=1){
    // Atributs de la classe (_a)
    // Si no s'especifica, el valor per defecte és 1
    this._a=valor;
}

get a(){
  // getter (no s'ha de dir igual que l'atribut!)
  return this._a;
 }

}
// Instanciació sense especificar valor
b=new Classe;
console.log(b.a);

// Instanciació amb valor
c=new Classe(4);
console.log(c.a);

    El resultat de l'script serà: 

    1
4

    Herència

    L'herència s'aconsegueix mitjançant la parala clau extends:

    class Sublclasse extends Superclasse{
    constructor(params={}){
        // Invocació al constructor de la classe pare
        super(valors);
    }

    metode(){
        // Invocació a mètodes de la classe pare
        super.metode();
    }
}

    Com podem veure, amb la paraula reservada super podem accedir a les propietats i mètodes del pare. Si la utilitzem en forma de funció (super(valores)) invoquem al constructor de la classe pare, amb els valors per defecte que li passem. Per part seua, quan la utilitzem en forma d'objecte (super.metodo()), el que fem és invocar a un mètode de la classe pare.

    Alguns aspectes a destacar sobre l'herència en Javascript:

    • El constructor d'una classe filla, necessàriament ha d'invocar a super abans d'utilitzar this.
    • Els constructors de les subclasses, han d'invocar a super, per a inicialitzar la classe, o bé retornar un objecte que reemplace l'objecte que no ha sigut inicialitzat.

    Vemaos finalment com quedaria l'exemple anterior amb aquesta nova sintaxi:
